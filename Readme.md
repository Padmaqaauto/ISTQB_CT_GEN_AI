# ISTQB CT GEN AI — Hands-on Repository

## Purpose

This repository is a chapter-wise learning companion for the hands-on exercises covered in the ISTQB CT GEN AI course. It keeps practical tasks, personal notes, observations, outcomes, and useful references together so they are easy to revisit and maintain.

Most repository content will be written in Markdown (`.md`) and edited in Visual Studio Code. The exact chapter names and exercise list will be added after checking the course syllabus and materials.
